# Правила проекта «РусОценка»

## Обязательный цикл после каждого изменения
1. Тесты и сборка (в неинтерактивном shell добавлять `/usr/local/bin` в `PATH`):
   `export PATH="/usr/local/bin:$PATH" && npm test && npm run build`
2. Всегда фиксировать и пушить изменения в `origin/main` (никогда не оставлять только локально). Публичный сайт: `https://maks1son.github.io/`.
3. Эталонное дело `19/0826-2` в `tests/model.test.js`, `tests/report.test.js` и `tests/dashboard.test.js` должно проходить на 100%.

## Архитектурные принципы продукта
- **Детерминированное ядро без ИИ в расчётах**: вся математика (сравнительный подход, ФСО №7, поправки Лейфера, веса, вариация `V ≤ 33%`, доли) выполняется строгим программным калькулятором в `src/model.js`. Никаких нейросетевых допущений в цифрах.
- **Прозрачность для возрастных оценщиков**: детальное раскрытие формул, шагов округления и источников («Где взят аналог») размещается **строго внутри дела и в отчёте**. Обзорные дашборды остаются минималистичными и чистыми.
- **Контроль достоверности**:
  - Долевая собственность строго `≤ 100%` (`1/1`) через точную дробную арифметику (`sumSharesFraction`, `getRemainingShareFraction`).
  - Перевод дела в статус «Готов» блокируется при несоблюдении критериев ФСО (`evaluateCaseQuality`).
  - Учёт рабочего времени разделяет чистую активность (порог простоя 45 сек + видимость вкладки) и простой.

## Генерация Word-отчёта (`src/report.js`)
- Отчёт формируется **строго 1-в-1 по мастер-шаблону** `public/templates/rosocenka_apartment_template.docx` через `JSZip` (сохраняются все 43 медиафайла, фоны, шрифты, размеры, рамки и колонтитулы; модифицируется только `word/document.xml` с сохранением `<w:rPr>`, `<w:pPr>`, `<w:tcPr>`).
- Принцип 3-х зон шаблона (по разметке заказчика):
  1. **Статика (без выделения)** — юридический каркас ФСО и наличие 4-х приложений (неизменны).
  2. **Периодические справочники (зелёная зона, 1 раз в 3–4 месяца)** — макроэкономика (`9.1.1`), соц-эконом обзор города (`9.1.2`), обзор сегментов (`9.3`), полис компании (`Таблица 8`), актуальная ссылка `statrielt.ru`.
  3. **Данные дела (жёлтая зона, под каждый объект)** — реквизиты дела/сторон, падежи, параметры объекта/дома/окружения, выборка рынка, расчёт сравнительного подхода и текстовые обоснования поправок.
- **4 обязательных Приложения в конце отчёта**: №1 документы оценщика, №2 документы на квартиру, №3 ссылки и скриншоты аналогов, №4 фотографии объекта.

## Ключевые файлы
- `src/model.js` — математика ФСО/Лейфера, доли, `evaluateCaseQuality`, справочник команды `TEAM_MEMBERS`.
- `src/storage.js` — `localStorage`, профили (Руководитель / Оценщик), трекинг времени и журнал событий.
- `src/report.js` — XML-патчинг мастер-шаблона `.docx`.
- `src/app.js` / `src/styles.css` — интерфейс и стили.
